# Agência de Viagens - Java
Projeto acadêmico desenvolvido em Java com foco na aplicação de conceitos de Programação Orientada a Objetos 
e regras de negócio.

# 📌 Sobre o projeto
A aplicação simula operações de uma agência de viagens, permitindo trabalhar com informações relacionadas a 
transporte, hospedagem, pacotes de viagem e vendas.

O projeto foi desenvolvido durante meus estudos de Desenvolvimento de Sistemas
com o objetivo de praticar estruturação de classes, métodos, objetos e relacionamento entre diferentes entidades.

# 💻 Tecnologias utilizadas
- Java
- Programação Orientada a Objetos
- NetBeans
- Git
- GitHub

# 🧠 Conceitos praticados
- Classes e objetos
- Encapsulamento
- Construtores
- Métodos
- Composição entre objetos
- Regras de negócio
- Organização de código

# 📂 Principais classes
- `Hospedagem` — São os dados e valores de hospedagem
- `Transporte` — representa o meio de transporte e seu valor
- `PacoteViagem` — reúne transporte, hospedagem e cálculos do pacote
- `Venda` — representa as informações relacionadas à venda
- `main` — responsável pela execução e interação com a aplicação
